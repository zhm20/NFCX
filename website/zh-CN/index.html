NFC 桌面工作台

轻而易举地操作 NFC 卡片。

面向授权 MIFARE Classic 操作的专注桌面工具：读取、写入、dump、密钥管理，以及已验证 PN532 UART 流程中的密钥恢复。

NFCX 是跨平台、开源、简单易用的 NFC 图形化桌面工具，支持 macOS、Windows 和 Linux。

为什么选择 NFCX

为跨平台 NFC 图形化体验而生。

01

跨平台

在 macOS、Windows 和 Linux 上提供一致的桌面体验。

02

开源

源码公开，使用 MIT License。

03

图形化界面

通过 GUI 完成 NFC 卡片操作，无需记忆命令行参数。

04

简单易用

把常用 NFC 操作集中在一个清晰的步骤中。

功能

在一个清晰的界面中完成工作流。

01

发现与查看

发现读卡器、扫描卡片，并查看 UID、ATQA、SAK 与卡片信息。

02

读取、编辑与恢复

认证 block、保存原始 dump、重新加载，并对每次写入进行回读验证。

03

密钥与恢复

扫描常见密钥，并在已授权时运行 PN532 UART 可用的恢复路径。

04

写入安全

检查 dump 、BCC、访问控制位、换卡情况与受保护的 block 0 操作。
